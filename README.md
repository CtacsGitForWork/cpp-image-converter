# Универсальный конвертер изображений

## Описание
Конвертер позволяет преобразовать растровые изображения из одного формата в другой без потери качества. При этом сначала происходит чтение изображения и создание объекта класса Image, который представляет изображение в памяти, а затем запись этого объекта в конечном формате в файл. Используемые форматы: JPEG, PPM и BMP.

## Технологии:
* C++ 17, STL, ООП, полиморфизм
* PPM
* BMP
* JPEG
* CMake

## Системные требования
Компилятор С++, С++17, CMake 3.11, LibJPEG

## Запуск проекта
1. Скачайте файлы из текущего репозитория.
2. Скачайте исходные файлы библиотеки LibJPEG "jpegsr9f.zip" c официального [сайта](https://www.ijg.org/).
3. Разархивируйте "jpegsr9f.zip", перейдите в новую папку с файлом configure и создайте папку "release".
3. Из папки "release" в командной строке запустите скрипт конфигурации:\
`../configure --enable-shared=no CPPFLAGS="-O3" CFLAGS="-O3"`\
**если работаете с MinGw, укажите дополнительный параметр MAKE="mingw32-make".* 
4. В папке "release" должен появиться файл "Makefile". Запустите в папке "release" в командной строке утилиту make или mingw32-make:\
`make` 
5. Создайте в корневой папке проекта cpp-image-converter папку "libjpeg" и поместите в неё исходные файлы из архива "jpegs9fr.zip", из созданной ранее папки release и из release/.libs, чтобы получилась следующая структура файлов:\
	```
	libjpeg/
	|--include
	|  |--jconfig.h
	|  |--jerror.h
	|  |--jmorecfg.h
	|  |--jpeglib.h
	|--lib/
   	   |--Debug
   	   |  |--libjpeg.a
   	   |--Release
      	  |--libjpeg.a  
6. Создайте в корневой папке проекта папку "release" для сборки проекта, перейдите в неё в командной строке и запустите cmake:\
`cmake ../ImgConverter -DCMAKE_BUILD_TYPE=Release -DLIBJPEG_DIR=<абсолютный путь к пакету libjpeg>`\
**если работаете с MinGw, укажите дополнительный параметр -G "MinGW Makefiles".* 
7. Запустите сборку проекта в командной строке:\
`cmake --build .`\
Проект собран.
8. Чтобы конвертировать изображения нужно в командной строке (находясь в папке "release" проекта) набрать:\
`imgconv <имя исходного изображения с расширением> <имя выходного файла с расширением>`
Если все шаги проделаны правильно, изображение сконвертируется без потерь.

## В конвертере изображений реализованы:
* отдельная библиотека для конвертирования изображений ImgLib
* функции чтения и записи для каждого формата изображений
* класс Image, отвечающий за представление изображения в памяти компьютера
* исключения, которые сообщают о неверном формате изображения и ошибках чтения/записи
* единый интерфейс для чтения/записи разных форматов


## Особенности конвертера изображений:
* изображение хранится в виде строки в std::vector
* у всех форматов изображения одинаковый интрефейс, что позволяет в едином стиле производить чтение и запись
* определение исходного формата изображения происходит автоматически при его чтении в зависимости от расширения файла
* для чтения и записи JPEG использована библиотека libjpeg
